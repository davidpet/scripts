Reference
Position (read-only)
x, y — pixel coordinates (0-based)
w, h — document width/height in pixels
Bit depth / quantization (read-only)
bpc — 8 or 16 (32-bit currently errors)
steps — 256 (8bpc) or 65536 (16bpc)
Ramp example:
const code = Math.floor((x / w) * steps);
r = g = b = code / (steps - 1);
RGB (read/write)
r, g, b, alpha — floats (normally 0..1)
Grayscale (read/write)
g, alpha — floats (normally 0..1)
Lab (read/write)
l, a, b, alpha — floats (normally 0..1)
Note: Lab channels are encoded; neutral a/b are around 0.5.
